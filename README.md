## mountainn

Flutter로 모바일 앱을 만들어요. 네이티브가 필요하면 Kotlin까지 내려갑니다.

- LightWeight에서 운동 머신과 Supabase Realtime으로 연동되는 회원 앱(Android · iOS)을 만들어요.
- ViewModel에 몰려 있던 코드를 Clean Architecture로 다시 짜고 앱을 pub workspace 패키지 20개로 나눴어요. 레이어 규칙은 pre-commit 훅과 CI가 대신 지켜요.
- 팀 코딩 규칙은 Claude Code 스킬로 직접 써 뒀어요. 사람이든 AI 에이전트든 같은 기준으로 코드를 짜고 리뷰해요.
- 크래시가 나면 사내 메신저로 바로 알림이 오게 Crashlytics 웹훅을 붙였어요.
- 문자 인증이 자꾸 안 와서 국내 SMS 업체 네 곳을 비교해 서버 OTP 인증 방식으로 옮겼어요.
- 요즘은 트레이너용 태블릿 앱을 새로 만들고 있어요.
- 삽질한 건 [블로그](https://mountaincoding.tistory.com/)에 적어 둡니다.
